# ИИшка — инструкция для тебя

Это чат-сайт с твоей ИИшкой. Ниже — всё по шагам, без предположений, что ты уже что-то знаешь.

## Что тут внутри

- `server.js` — программа-посредник. Она единственная видит твой API-ключ и характер ИИшки (там же лежит текст с её личностью — можно редактировать).
- `public/` — сама страница чата (то, что видит пользователь в браузере).
- `.env.example` — образец файла с настройками.

## Шаг 1. Поставить Node.js

Node.js — программа, которая умеет запускать такой код на компьютере.

1. Зайди на https://nodejs.org
2. Скачай версию с пометкой **LTS** (она стабильнее)
3. Установи как обычную программу (next, next, next)

Проверить, что всё встало: открой терминал (на Windows — "Командная строка" или PowerShell, на Mac — "Terminal") и напиши:
```
node -v
```
Если вылезла версия типа `v20.11.0` — всё получилось.

## Шаг 2. Настроить ключ

1. В папке проекта скопируй файл `.env.example` и переименуй копию в `.env`
2. Открой `.env` любым текстовым редактором (даже Блокнотом)
3. Вставь свой настоящий ключ от OpenRouter вместо `sk-or-твой-ключ-сюда`
4. Сохрани

**Важно:** файл `.env` никогда никому не показывай и не выкладывай в интернет — это как пароль от квартиры.

## Шаг 3. Запустить локально (проверить, что работает)

В терминале зайди в папку проекта и напиши:
```
npm install
```
(это скачает нужные библиотеки, подождать минуту)

Потом:
```
npm start
```

В терминале появится что-то вроде "ИИшка слушает на http://localhost:3000" — открой эту ссылку в браузере. Должен появиться чат.

## Шаг 4. Настроить характер (по желанию)

Открой `server.js`, найди блок `SYSTEM_PROMPT` — это текст, который объясняет модели, кто такая ИИшка и как себя вести. Можешь редактировать прямо там, сохранить файл и перезапустить сервер (`npm start`).

## Шаг 5. Выложить сайт в интернет

Пока на компьютере — сайт видишь только ты. Чтобы его увидели другие, нужен хостинг. Когда дойдёшь до этого шага — напиши мне, распишу конкретно (проще всего — Render.com, там бесплатный план и всё через кнопки, без консольных команд).

## Что уже сделано

- Характер: серьёзная с иронией, без подхалимства, без лишнего доказывания правоты — всё как ты описала
- Никаких круглых эмодзи по умолчанию
- Каомоджи (◕‿◕) добавляются сами, раз в случайные 5-9 сообщений
- Если попросить убрать каомоджи/эмодзи в чате — она перестанет их использовать
- ИИшка может написать первой, если ты замолчала на 45 секунд (это настраивается — см. `IDLE_MS` в `public/app.js`)
